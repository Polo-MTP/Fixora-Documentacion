**Fixora** es una plataforma que conecta a **clientes** con **proveedores de servicios**. Los proveedores registran sus negocios y sucursales, pasan por un proceso de verificación de documentos y asignan a sus empleados las solicitudes que reciben. El cliente pide el servicio, conversa con el proveedor por chat, paga y al final ambos se dejan una reseña.

El proyecto se desarrolla en tres frentes:

| Frente | Tecnología |
| --- | --- |
| App móvil | Kotlin |
| Web | Angular |
| Backend | Node.js |
