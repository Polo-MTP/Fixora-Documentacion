| Herramienta | Para qué la usamos |
| --- | --- |
| **Git** | Control de versiones distribuido: historial, ramas por tarea y commits con [Conventional Commits](/docs/desarrollo/commits). |
| **GitHub** | Repositorios remotos, pull requests, revisión de código y reglas de protección de ramas. |
| **GitHub Actions** | Pruebas y despliegues automáticos cada vez que llega código nuevo (CI/CD). |
| **Plane** | Backlog, sprints y tareas. El ID de cada tarea (`APP-XX`) da nombre a las ramas y aparece en los commits. |
| **Fumadocs** | Este sitio de documentación, escrito en MDX. |

La justificación de por qué elegimos Git y GitHub está en [Control de versiones](/docs/proyecto/unidad-2/control-de-versiones).
