La base de datos de Fixora tiene **36 tablas** agrupadas en **7 módulos**. Se generó a partir del modelo `Fixora DB (corregido).drawio`.

## Convenciones

- Todos los id son **BIGINT**. En el modelo, `string` equivale a **VARCHAR**.
- **Llave primaria (PK):** la columna `UniqueID` de cada tabla.
- **Llaves foráneas (FK):** las columnas `*_id` y similares. La tabla de destino aparece en la columna *Llave* (`FK → tabla`).
- **Polimórfica:** un id cuya tabla de destino depende de otra columna (por ejemplo `entity_id` junto con `entity_type` en `notifications`).
- Las fechas con hora usan `DATETIME`.
- Las bajas son **lógicas**, con el campo `active`: los registros no se borran, se desactivan.
- Los id pueden ir vacíos (nulos) según el caso; por ejemplo, un empleado que aún no se asigna a una solicitud.
