**Fixora: plataforma de solicitud y gestión de servicios entre clientes y proveedores.**

En esta sección vive cada entregable formal del proyecto de la asignatura **Desarrollo Web Integral** (Universidad Tecnológica de Torreón), con el docente **Jesús Del Toro**.

## Equipo

El equipo está formado por **5 integrantes** que trabajan en paralelo sobre la app móvil (Kotlin), la web (Angular) y el backend (Node.js).
